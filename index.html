How this lab works

  1. Enter your name and campaign/project once on any tool page — it carries over to the others.
  2. Your answers and uploaded images autosave to this browser only as you type.
  3. Use Export JSON at the end of a session to back up your work, or to move it to another computer — use Import JSON there to pick up where you left off.
  4. When an assignment is ready, use Download PDF and upload that file to Google Classroom.
  5. Nothing here is stored on a server, so clearing your browser data will erase unsaved work — export often.
